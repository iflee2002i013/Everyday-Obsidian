# 反馈1
关于阅读回顾起始年份，这个设计不太合理，直观上来说就是每半年一页就可以了。所以功能上只需要点击"<<"上一年，点击"<"上一月这个功能就行。甚至不需要弹窗提示选择月份了。

只需要在Memory Board的顶部的年月切换部分加上"<<"按钮即可

## 回执

已阅读并确认这次第五阶段反馈。

我的理解是：当前已经实现的“点击顶部时间范围弹出月份选择器”方案不符合预期，后续应改为更直接的半年分页导航，不再需要弹窗选择月份。

调整方向应为：

- 取消或不使用 `MemoryBoardPeriodPickerModal` 这类月份选择弹窗。
- Memory Board 顶部导航保留按半年翻页的 `<` / `>`。
- 在顶部年月切换区域增加 `<<` / `>>`，用于按年份跨度切换。
- 用户不需要手动选择任意起始月份，Memory Board 继续以“每半年一页”的方式运作。

本次只完成阅读和回执记录，尚未修改代码。
