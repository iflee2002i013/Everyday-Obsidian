# 漏洞修复回执日志

修复日期：2026-05-24

修复依据：`开发资料/漏洞修复1/Everyday插件漏洞检查报告.md`

## 已修复

1. 高危：停止删除用户 frontmatter 字段
   - `DiaryStorageService.writeFrontmatter()` 现在只写入 `mood_label`、`mood_emoji`、`summary`。
   - 不再删除 `mood`、`mood_score`、`summery`、`date`、`created_at`、`updated_at` 等用户可能自定义的 YAML 字段。

2. 中危：补充路径穿越校验
   - `path.ts` 对日记目录、日记文件名格式、Daily Notes 文件夹/格式、模板路径统一拒绝 `.` 和 `..` 路径段。
   - 保留合法的多级目录格式，例如 `YYYY/MM/YYYY-MM-DD`。

3. 中危：补充异步刷新异常兜底
   - `refreshMonthViews()` 和 `refreshMemoryBoardViews()` 对每个视图单独 try/catch。
   - 定时刷新链路增加 `.catch()`，避免后台文件事件造成 unhandled rejection。

4. 中危：降低视图 DOM 结构依赖
   - `MonthMemoryView` 和 `MemoryBoardView` 改用 `this.contentEl`，不再依赖 `containerEl.children[1]`。

5. 中低危：补充打开/加载失败提示
   - 月视图打开已有日记失败时显示 Notice。
   - 快速记录弹窗加载已有记录失败时显示 Notice，并降级为空表单，避免弹窗直接失败。

6. 低危：设置变更后刷新范围补齐
   - 日记目录、年份子目录、命名方式、文件名格式变更后，统一刷新 Month View 和 Memory Board。
