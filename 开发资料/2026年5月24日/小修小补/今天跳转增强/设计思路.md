# 今天跳转增强设计思路

## 问题

侧边栏月视图已有“今天”按钮，但原实现只把当前年月切换到今天所在月份。月份切换后，如果当天行不在当前可见区域中间，用户仍然需要手动滚动查找。

每天打开 Obsidian 时，侧边栏恢复到月视图后，也应该直接让今天这一行出现在视图中间附近。

## 原因

`MonthMemoryView.goToCurrentMonth()` 只更新 `currentYear`、`currentMonth` 并调用 `render()`。列表行和日历格已经通过 `is-today` 类高亮当天，但渲染后没有执行 DOM 滚动定位。

## 实现策略

1. 给 `MonthMemoryView.render()` 增加可选参数：
   - `scrollToToday`：是否在渲染完成后定位今天。
   - `behavior`：滚动行为，支持 `auto` 和 `smooth`。
2. `onOpen()` 首次打开时调用 `render({ scrollToToday: true, behavior: "auto" })`，让侧边栏恢复后立即定位今天。
3. “今天”按钮继续调用 `goToCurrentMonth()`，但该方法改为渲染后平滑滚动到今天。
4. 普通 `refresh()` 仍调用默认 `render()`，不自动滚动，避免后台文件变更刷新时打断用户正在浏览的位置。
5. 渲染列表或日历后，用 `requestAnimationFrame()` 等待 DOM 更新，再查找 `.is-today` 并调用 `scrollIntoView({ block: "center", inline: "nearest" })`。

## 影响范围

- 只修改侧边栏月视图 `MonthMemoryView`。
- 不新增设置项。
- 不修改日记文件格式、插件数据结构或 Memory Board 行为。
- 列表模式和日历模式共用现有 `.is-today` 类，因此同一套滚动逻辑即可覆盖两种模式。
