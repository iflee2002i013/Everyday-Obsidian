# 今天跳转增强测试结果

## 自动验证

- 已通过：在 `.obsidian/plugins/Everyday` 执行 `npm run build`。
- 构建命令完成了 TypeScript 检查和 esbuild 生产打包，没有报错。

## 手动验证清单

- 待人工验证：打开 Obsidian 后，侧边栏月视图自动显示今天所在月份，并把今天定位到可见区域中间附近。
- 待人工验证：在其他月份点击“今天”，视图切回今天所在月份并平滑滚动到今天。
- 待人工验证：已经在本月但滚动位置不在今天附近时，点击“今天”仍会定位今天。
- 待人工验证：列表模式下今天定位正常。
- 待人工验证：日历模式下今天定位正常。
- 代码路径已确认：文件变更触发的普通 `refresh()` 仍调用默认 `render()`，不会传入 `scrollToToday`，因此不会主动滚回今天。

## 结论

- 自动构建通过。
- 交互行为仍需在 Obsidian UI 中人工确认。
